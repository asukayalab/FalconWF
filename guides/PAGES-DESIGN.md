# Halaman & Desain

Tersedia mulai build lokal alpha.19. Menu ini mengubah tampilan Page melalui template theme aktif terpasang, bukan mengambil file langsung dari GitHub.

1. Buka Falcon WF → Halaman & Desain.
2. Temukan halaman; gunakan nomor halaman daftar bila perlu.
3. Pilih template, centang persetujuan lalu Apply desain halaman.
4. Buka Lihat halaman atau Preview untuk memeriksa hasil. Edit isi membuka editor WordPress.

Pilihan Template di editor Page dan dashboard memakai pengaturan WordPress yang sama. Mengubah salah satunya terlihat di tempat lain setelah dimuat ulang. Isi, URL dan status publikasi tidak diubah oleh Apply. Pada Page yang sudah terbit, tampilan berubah langsung.

Template tambahan harus disediakan oleh theme aktif. File PHP biasa dalam repo tidak otomatis menjadi template yang bisa dipilih. Jika hanya Default tersedia, desain belum menyediakan named Page template. Beranda khusus front-page.php mengikuti aturan WordPress sehingga dapat mengesampingkan pilihan template Page.

Jika template lama hilang, Falcon menampilkan masalah; pilih pengganti atau Default secara sadar. Bila pengguna lain sedang mengedit, tunggu selesai. Bila form kedaluwarsa karena halaman atau theme berubah, muat ulang dan review.

Apply berjalan satu halaman per form. Belum ada batch apply, registry peran Kontak/Tentang, auto-create Page, preview galeri Falcon, import custom field proyek atau tools MCP untuk pointing template. Instal/update desain dan aktivasi theme tetap langkah terpisah yang dijalankan manusia.
