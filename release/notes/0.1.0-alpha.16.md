Pembaruan Falcon WF:

- Pengguna cukup memilih jalur Stabil atau Uji coba. Versi uji coba terbaru ditemukan otomatis tanpa mengisi tag versi.
- Sumber pembaruan FWF tersedia secara bawaan; pengaturan teknis dilipat untuk pengelola.
- Halaman Pembaruan menampilkan versi terpasang, versi tersedia, catatan perubahan dan tombol yang menyebut komponen tujuan.
- Kandidat diperiksa ulang sebelum pemasangan; paket berubah atau versi lebih lama ditolak.
- Push ke main menjalankan pemeriksaan dan pengujian WordPress terisolasi. Versi baru yang lulus dibuat menjadi GitHub prerelease dengan ZIP plugin, ZIP theme dan manifest secara otomatis; versi yang sudah diterbitkan tidak ditimpa.

Build pengembangan untuk pengujian local/staging. Rilis ini belum merupakan FWF 0.1 stabil. Uji update hosting serta penerimaan provider dan connector AI sungguhan masih menjadi pekerjaan terpisah.
