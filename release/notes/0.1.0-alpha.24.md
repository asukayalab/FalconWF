- Core dan proyek menyediakan Stabil terbaru, Terbaru termasuk uji coba, dan Tag release tertentu di semua environment.
- Stabil memilih versi stabil tertinggi dari seluruh release published; opsi termasuk uji coba memilih versi tertinggi stabil/alpha/beta/rc. Draft tidak dipilih, discovery tetap bounded dan gagal jika tidak lengkap.
- Kolom tag mengikuti pilihan release tertentu dan tetap terkunci sampai pengelola menggantinya. Koneksi repo proyek dapat menemukan identitas dari prerelease tanpa mengganti environment server.
- Review, provenance, compatibility, checksum dan larangan downgrade/aktivasi otomatis tetap berlaku. Prerelease ini belum menutup seluruh gate0.1.
